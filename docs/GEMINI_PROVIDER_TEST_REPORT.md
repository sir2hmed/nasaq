# Gemini Provider Test Report

Automated coverage verifies admin-only routing access, encrypted persistence, masked responses, failure-before-activation, mocked successful verification, and primary activation. Gemini uses the shared bounded provider probe and Gemini adapter; no real API key is used in tests.

Manual acceptance: choose Google Gemini, select `gemini-3.7-flash`, enter only the Gemini API key, select **Save & Test Connection**, then activate after a verified result. The key must display only in masked form after saving.
